# Mallorca Garden Solution — Landing

Landing publicitaria de mantenimiento de jardín premium en Mallorca.

## Estructura
- `index.html` — la landing (HTML + CSS, sin dependencias de build)
- `img/` — 5 imágenes del cliente

## Despliegue
Sitio estático. No requiere build. Vercel lo detecta automáticamente
como "Other / static" y sirve `index.html` en la raíz.

## Pendientes
- Sustituir `{{TELEFONO}}` y `{{WHATSAPP}}` por los datos reales del cliente
- Conectar el formulario a un destino (email / CRM / Formspree) — ahora es demo
